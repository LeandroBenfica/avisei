Este repositório armazena o dataset mestre e os algoritmos desenvolvidos para a dissertação de mestrado em Segurança Cibernética pela Universidade de Brasília (UnB). O projeto integra dados do Tor Metrics, CTIR Gov e CERT.br (2022 a 2025) utilizando Análise Espectral e Isolation Forest para identificar anomalias e gerar indicadores de risco.

Estrutura do Repositório
Dataset: Arquivo mestre com a fusão das séries temporais.

Algoritmos: Scripts para processamento, detecção de anomalias e visualização.

Documentação: Metodologia de fusão multivariada de dados.
